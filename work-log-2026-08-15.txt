Tutor Connect - Updates (August 15, 2026)
==========================================

Sign Up & Sign In:
- After verifying email, users are now signed in automatically (no need to log in again)
- If a user signs in without verifying their email, they are taken back to the verification page
- Added loading indicators so pages don't feel frozen while signing in
- Fixed the name field example text to show a Bangladeshi name

General:
- All "Register" buttons across the site now go to one single sign-up page
- Sidebar menu: "Money" is now called "Payment"
- Sidebar menu: new collapsible "Shop" section

Profile Page:
- Profile page now shows a checklist explaining what the completion percentage means, with links to finish the missing steps
- Students can now also edit their CGPA (previously tutors only); clearing the field removes it
- Profile updates now refresh the completion score on the profile and dashboard immediately
- The completion checklist now opens from a small "info" icon next to the percentage (no longer takes up space on the page), and tutor-only steps are hidden from students

Performance / Technical:
- Fixed the app sometimes showing old content after an update (service worker cache now refreshes properly)
- Push notifications no longer run in the development environment, which was causing broken pages during development

Wallet & Payments:
- All money amounts now show as "TK" (e.g. "500 TK") instead of the "৳ BDT" style, across the wallet, dashboard, and admin pages
- Deposit form: "TK" now appears after the amount, which reads more naturally

Small Fixes:
- After saving the profile, the success/error message now scrolls into view on mobile so users can see the result
- Account menu stays compact on small phone screens (shows only the avatar initials)
